## <img src="./assets/icons/code-xml.svg" width="22" height="22" alt=""> Usage | 使用方式

1. 打开 [README 编写 Prompt](./README_STYLE_PROMPT.md)，复制全文，并填写其中的任务信息表
2. 将 Prompt、目标仓库资料、现有 README 与本次修改要求一同提供给 AI
3. 对照 [完整示例](./README_EXAMPLE.md) 检查生成内容，将实际使用的 [SVG 资源](./assets/) 复制到目标文档对应目录
4. 在 GitHub 中检查图片、徽章、链接和布局，补齐明确标出的待填信息后再发布

> [!TIP]
> 阅读示例时切换到 GitHub 的 **Code** 视图，可以直接查看作者注释、HTML 双栏、提示块和页脚的源码写法

## <img src="./assets/icons/circle-check.svg" width="22" height="22" alt=""> Check | 使用要点

- 顶部以隐藏注释记录作者，协会透明 SVG Logo 保持 132px 宽度
- 协会专属徽章必须保留，其余徽章按文档实际内容选用
- 作者、起始年份、技术栈和许可证以目标仓库资料为准
- 正文采用中英双语标题与紫色 SVG 图标，按内容适量使用 GitHub 提示块
- 本地图标、徽章和对应许可说明随文档一起复制；移动 Markdown 文件时同步调整相对路径

> [!NOTE]
> 示例中的起始年份等占位文字用于说明填写位置，不代表目标项目的实际信息。Prompt 默认只生成或修改文档，提交与发布需要明确指令
