## <img src="./prompts/readme/assets/icons/code-xml.svg" width="22" height="22" alt=""> Usage | 使用方式

1. 在目录中选择所需 Prompt，阅读该主题目录内的使用说明
2. 将完整 Prompt、实际资料与本次要求一同提供给 AI
3. 按主题说明复制需要的资源，并核对生成内容

> [!NOTE]
> 示例中的作者、年份和技术栈不能直接当作目标项目的事实，使用时以实际资料为准

## <img src="./prompts/readme/assets/icons/folder-open.svg" width="22" height="22" alt=""> Add a Prompt | 新增主题

- 在 `prompts/` 下为新主题建立独立目录
- 将该主题的使用说明、Prompt、示例与资源放在同一目录，保持相对路径有效
- 在本页的 Prompt 目录表中添加入口
